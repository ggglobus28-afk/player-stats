# BodyCount

Client-side Fabric mod for Minecraft that adds a fourth tab to the statistics
screen: kills and deaths, totems popped and lost, chat kill pairs, per-server
profiles and themes.

**Русская версия:** [README.ru.md](README.ru.md)

## Features

- Per-player table with kills / deaths and totems popped / lost.
- Chat kill pairs: who killed whom and how many times.
- Separate statistics for each server profile.
- Five themes. The default one matches the vanilla statistics screen; the other
  four restyle the mod's widgets, including buttons.
- English and Russian localization.
- Optional Mod Menu integration.

The mod is client-side only and records events visible to the client.

## Compatibility

| Minecraft | File | Java | Fabric Loader |
|---|---|---|---|
| 1.21.11 | `bodycount-<version>-mc1.21.11.jar` | 21+ | 0.16.0+ |
| 26.1 / 26.1.1 / 26.1.2 | `bodycount-<version>-mc26.1.jar` | 25+ | 0.19.5+ |
| 26.2 / 26.3 | `bodycount-<version>-mc26.2-26.3.jar` | 25+ | 0.19.5+ |

Install one jar only, matching the game version. Fabric API is not required.

## Installation

1. Install Fabric Loader.
2. Put the matching jar in the `mods` folder.
3. Open **Esc → Statistics → BodyCount**.

Earlier builds were named Player Stats. Remove the old jar before installing
BodyCount; both register the same mod.
