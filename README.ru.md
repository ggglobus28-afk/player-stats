# BodyCount

Клиентский Fabric-мод для Minecraft, который добавляет четвёртую вкладку в меню
статистики: убийства и смерти, снятые и потерянные тотемы, пары убийств из чата,
профили серверов и темы оформления.

**English version:** [README.md](README.md)

## Возможности

- Таблица по игрокам: убийства / смерти и снятые / потерянные тотемы.
- Пары убийств из чата: кто кого убил и сколько раз.
- Отдельная статистика для каждого профиля сервера.
- Пять тем. Стандартная совпадает с меню статистики; остальные оформляют
  элементы мода, включая кнопки.
- Локализация: русский и английский.
- Поддержка Mod Menu по желанию.

Мод работает на клиенте и учитывает только события, видимые клиенту.

## Совместимость

| Minecraft | Файл | Java | Fabric Loader |
|---|---|---|---|
| 1.21.11 | `bodycount-<версия>-mc1.21.11.jar` | 21+ | 0.16.0+ |
| 26.1 / 26.1.1 / 26.1.2 | `bodycount-<версия>-mc26.1.jar` | 25+ | 0.19.5+ |
| 26.2 / 26.3 | `bodycount-<версия>-mc26.2-26.3.jar` | 25+ | 0.19.5+ |

Устанавливайте только один jar, соответствующий версии игры. Fabric API не
требуется.

## Установка

1. Установите Fabric Loader.
2. Положите подходящий jar в папку `mods`.
3. Откройте **Esc → Статистика → BodyCount**.

Ранние сборки назывались Player Stats. Перед установкой BodyCount удалите
старый jar: оба файла регистрируют один и тот же мод.
